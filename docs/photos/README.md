Put recipe photos here, named after the recipe id (for example `butter-chicken.jpg`).
Then set `"photo": "photos/butter-chicken.jpg"` for that recipe in `docs/data/recipes.json`.
Recipes with no photo show a coloured placeholder with initials. Use photos you own or that are licensed for this use (check the licence and attribution rules).
Keep each photo under about 200 KB (resize to roughly 800 px wide) so the page stays fast.
